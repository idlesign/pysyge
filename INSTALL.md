# pysyge installation

Python `pip` package is required to install `pysyge`.

## From sources

Use the following command line to install `pysyge` from sources directory (containing `pyproject.toml`):

```shell
pip install .
```

## From PyPI

Alternatively you can install `pysyge` from PyPI:

```shell
pip install pysyge
```

Use `-U` flag for upgrade:

```shell
pip install -U pysyge
```
